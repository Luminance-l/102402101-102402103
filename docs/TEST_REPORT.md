# 校园拾光单元测试报告

## 工具与方法

测试使用 Node.js 自带的 `node:test` 与 `node:assert/strict`，不依赖网络和第三方包。业务逻辑集中在 `js/store.js`，同时兼容浏览器全局变量和 CommonJS，因此可以脱离界面自动测试。

测试设计以白盒分支覆盖为主，并结合等价类与边界值：有效/无效表单、空字符串、最短描述、无效时间、正常/非法状态、存在/不存在 ID、有/无搜索结果、单条件/组合条件。

## 测试用例

| 编号 | 测试内容 | 预期结果 |
| --- | --- | --- |
| 1 | 完整有效表单 | 校验通过 |
| 2 | 名称只有空格 | 校验失败 |
| 3 | 描述少于 5 字 | 校验失败 |
| 4 | 时间格式无效 | 校验失败 |
| 5 | 创建寻物信息 | 状态为“寻找中” |
| 6 | 创建招领信息 | 状态为“待认领” |
| 7 | 名称关键词搜索 | 返回校园卡 |
| 8 | 地点关键词搜索 | 返回图书馆钥匙 |
| 9 | 类型筛选 | 返回两条招领信息 |
| 10 | 类别与状态组合筛选 | 只返回已归还耳机 |
| 11 | 时间排序 | 新信息在前 |
| 12 | 更新合法状态 | 成功且原数组不变 |
| 13 | 更新不存在 ID | 返回失败 |
| 14 | 更新非法状态 | 拒绝写入 |
| 15 | 删除已有信息 | 数量减少一条 |
| 16 | 信息统计 | 总数、处理中、已解决正确 |

## 运行命令

```bash
node --test tests/store.test.js
```

## 评价

这些测试覆盖了核心数据函数的主要正常分支、异常分支和边界输入，可防止筛选、状态更新与表单校验在后续迭代中回归。浏览器剪贴板、文件选择和视觉布局属于 DOM/环境行为，另外通过 Chrome 人工走查验证。
