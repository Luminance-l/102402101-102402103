# 校园拾光 - 校园失物招领 Web 应用

结对成员：章玲（102402101）、吴雅晴（102402103）。仓库名称按作业要求为 `102402101-102402103`。

## 功能

- 发布寻物信息和招领信息，校验必填字段并支持可选图片。
- 集中浏览全部信息，按关键词、类型、类别和状态组合筛选。
- 查看详情和发布者联系方式，支持一键复制联系方式。
- “我的发布”中更新“已找到/已归还”状态或删除记录。
- 使用 `localStorage` 持久保存演示数据，无需后端和数据库。
- 响应式布局，可在 Chrome 桌面端和窄屏设备中使用。

## 运行方法

### 直接运行（助教推荐）

1. 下载或克隆项目全部文件。
2. 使用 Google Chrome 打开根目录中的 `index.html`。
3. 无需安装依赖、无需启动服务器即可体验所有核心功能。

若浏览器限制剪贴板功能，可使用本地服务器：

```bash
python -m http.server 8080
```

然后在 Chrome 访问 `http://localhost:8080`。

## 单元测试

需要 Node.js 18 或更高版本。项目不依赖第三方测试框架，直接运行：

```bash
node --test tests/store.test.js
```

测试覆盖表单校验、默认状态、关键词匹配、组合筛选、排序、状态更新、异常输入、删除和统计等场景。

## 数据说明

数据保存在浏览器 `localStorage` 的 `campus-light-items-v1` 项中。第一次运行会加载四条演示数据。若要恢复初始数据，在 Chrome 开发者工具中删除该项并刷新页面即可。

## 浏览器

开发与测试统一使用 Google Chrome。Edge 等 Chromium 浏览器也可运行，但最终验收以 Chrome 为准。
